V GRAPHIC WORLD — FREE PORTFOLIO WEBSITE
=========================================

YE WEBSITE GITHUB PAGES PAR FREE PUBLISH KI JA SAKTI HAI.

FILES:
- index.html       Website ka structure
- style.css        Design, colors, mobile layout
- script.js        Category filters aur interactions
- projects.js      Project images, videos, email aur WhatsApp yahin edit karein
- assets/          Apni image/video thumbnails yahan rakh sakte hain

GITHUB PAR UPLOAD:
1. GitHub par login karein.
2. Apni repository banayein: YOUR-USERNAME.github.io
   (YOUR-USERNAME ko apne GitHub username se replace karein.)
3. Is ZIP ke andar ki saari files/folders repository ke ROOT mein upload karein.
   Dhyan: index.html root mein hona chahiye, kisi extra folder ke andar nahi.
4. Commit changes karein.
5. Repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Kuch minute baad https://YOUR-USERNAME.github.io/ kholein.

APNE PROJECTS KAISE BADLEIN:
1. GitHub repository mein projects.js file kholein.
2. Pencil/Edit icon dabayein.
3. Sample project ka title, category aur image URL badlein.
4. Video ke liye type: "video" aur videoUrl mein YouTube EMBED URL dein.
   Example: YouTube link https://www.youtube.com/watch?v=VIDEO_ID
   Embed URL: https://www.youtube.com/embed/VIDEO_ID
5. Email aur WhatsApp fields ko apni details se badlein.
6. Commit changes karein. Website kuch minute mein update ho jayegi.

LOCAL IMAGES:
- Repository mein assets naam ka folder banayein.
- Apni image upload karein, jaise assets/packaging-design.jpg
- projects.js mein image: "assets/packaging-design.jpg" set karein.

VIDEO FILES:
- Bade MP4 videos ko seedhe GitHub repository mein upload karne se bachein.
- YouTube par Unlisted video rakhkar embed URL use kar sakte hain. Unlisted ka matlab link wale log video dekh sakte hain.
- Is starter template mein video thumbnail par click karne se video link nayi tab mein khulta hai.
- Public website ke code mein passwords, GitHub tokens ya API keys kabhi na daalein.

NOTE:
Project cards mein sample imagery hai; ye aapke actual portfolio projects nahi hain.
Publish karne se pehle projects.js mein sample details aur contact details replace karein.
